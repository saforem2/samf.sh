## Already implemented on this branch

- Code blocks use square frames, language chips, and the existing ANSI colors.
- Tables use roomier square cells and neutral header separators; the `ezpz status` snapshot maps host and job states to color.
- The About page tables use the default table treatment. Nested-list rails are removed; definition lists and the table of contents retain their structural styling.
- Iosevka25 Condensed is available as an optional code font.
